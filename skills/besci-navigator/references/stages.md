# Stages and how to hear them

The library's seven stages, how they map to three common frameworks, and the phrases users say that place them at each stage. `other` exists for skills that fit none.

| Stage | What it covers | BIT TEST | Busara AUDAS | TAF four-level eval | Users say |
|---|---|---|---|---|---|
| define | Turn a goal, population, or outcome into something specific enough to work on | Target | Assess | Level 0, theory of change | "we want to improve X", "our goal is", "we're not sure what behavior to focus on" |
| diagnose | Explain why the current behavior pattern exists | Explore | Understand | Level 1, formative research | "why aren't they", "people drop off", "we don't know what's stopping them" |
| design | Produce intervention content, levers, messages, strategy | Solution | Design | Level 1, prototype | "what should we do", "design a message", "which nudge", "we have an idea for" |
| measure | Choose, adapt, or build instruments | Trial (measurement) | Assess | Level 2, outcome measures | "how do we measure", "is there a scale for", "pretest our survey", "validate" |
| test | Plan a pilot, experiment, or evaluation | Trial | Assess | Level 3, experimental evaluation | "run an RCT", "pilot", "A/B test", "sample size", "pre-registration" |
| analyze | Analyze data from a test and interpret it | Trial (analysis) | Assess | Levels 3 and 4, analysis | "we have the data", "did it work", "effect size", "results" |
| implement | Roll out, adapt, scale, and report | Scale | Scale | Level 4, scale and welfare | "scale up", "roll out", "adapt for a new region", "write up what we did" |

Notes on reading stage from a request:

- "Retention is bad" is a diagnose request unless the user already knows why, in which case it is design.
- "We need a baseline" is measure, but check whether the outcome has been defined; if not, define comes first.
- A user with data in hand and no plan for it is analyze, even if they describe the program from the beginning.
- "Localize this intervention" is implement with a design loop inside it.
- Pre-mortems and risk reviews sit between design and test; place them as parallel steps.

Frameworks referenced: Behavioural Insights Team, *Test, Learn, Adapt* (2012) and *EAST* (2014); Busara, AUDAS framework (2025); The Agency Fund, four-level evaluation framework, https://eval.playbook.org.ai/. The crosswalk is a navigation aid, not a claim that the frameworks are equivalent.
