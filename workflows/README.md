# Workflows

A **workflow** is a recommended set of skills for a task too big for one skill, with the relationships between the skills stated: which comes after which, which can run in parallel, which are independent, and where a human has to decide before the next step. Even "use these three, in any order, but A before B" is a workflow.

Workflows live here as single markdown files, one per workflow, following `WORKFLOW-TEMPLATE.md`. They are not skills and are never placed in `skills/`.

There are no workflows yet. `besci-navigator` drafts one in guide mode whenever a user's goal spans several stages; a drafted workflow that proves useful can be submitted here through the normal contribution process. Phase 2 of the partnership invites expert organizations to contribute the workflows they actually use.

To propose one, open an issue or submit a pull request adding `workflows/<name>.md`.
